# Matriz de coincidencias y contradicciones — [RUC]

> Cotejo sistemático de versiones por tema controvertido. Una fila por tema; una columna por declarante o fuente objetiva.

## 1. Matriz principal

| Tema controvertido | [Declarante 1] (fecha decl.) | [Declarante 2] (fecha decl.) | Evidencia objetiva (doc./digital/pericial) | Calificación² | Relevancia típica³ |
|---|---|---|---|---|---|
| | | | | C / CP / X / XO | alta / media / baja |

² **C** = coincidencia plena · **CP** = coincidencia parcial · **X** = contradicción entre declarantes · **XO** = contradicción de una versión con evidencia objetiva.
³ Relevancia respecto de los elementos del tipo penal investigado o de la credibilidad del declarante.

## 2. Análisis de cada contradicción relevante (X / XO)

Para cada contradicción de relevancia alta, desarrolla en prosa:

1. **Enunciado preciso de la divergencia**, con cita de foja o archivo.
2. **Explicaciones alternativas**: error de memoria, percepción parcial, transcurso del tiempo, mendacidad, coordinación de versiones.
3. **Evidencia dirimente disponible o por obtener** (diligencia concreta).
4. **Impacto en la teoría del caso** de cada explicación alternativa.

## 3. Patrones transversales

- Coincidencias sospechosamente literales entre declarantes (posible concertación).
- Evolución de versiones de un mismo declarante entre declaraciones sucesivas.
- Temas sistemáticamente evadidos por uno o más declarantes.
